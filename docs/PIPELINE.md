# PIPELINE — ทีมสร้าง prompt ทำงานยังไง

จากไอเดียหนึ่งข้อ ไปเป็น prompt พร้อมวางใน workflow โดยผ่านหลายชั้น (แต่ละชั้นคือ skill หนึ่งตัวใน `.claude/skills/`) agent จะเรียกให้เอง นักเรียนแค่ตอบคำถามและเลือก

## ลำดับชั้น
```
ไอเดีย + ตัวละคร (+ แพลตฟอร์ม/ความยาวถ้ามี)
   │
   ▼  content-director        อ่าน character DNA + content_dna → ตัดสินประเภทเนื้อหา กลไกมุก และ "บทพูดที่ตัวละครจะพูดจริง"
   ▼  delivery-format-selector  ตัดสินว่าจะทำเป็นอะไร (คลิปสั้น / ภาพชุด / carousel / story)
   ▼  format-router             เลือกสไตล์กล้อง-ท่าทาง จาก format_bibles/ (เช่น tripod_casual, selfie_cam, dance_pose_copy)
   ▼  prompt-enhancer           เติมท่าทางธรรมชาติ (สายตา การขยับเล็กๆ จังหวะ) และขัดบทให้เป็นภาษาพูด
   ▼  comfyui-compiler          แปลงเป็น prompt เฉพาะโมเดล (model_specs/ เช่น minimax-h3) พร้อมแบ่ง segment ถ้ายาวเกิน ~15 วินาที
   ▼  prompt-validator          (ปิดอยู่ชั่วคราวในต้นฉบับ) ตรวจความถูกต้องก่อนเอาไปรัน
   ▼
   content_output/<ตัวละคร>/<วันที่>/item01_compiled_prompt.txt   → ก๊อปไปวางใน workflow
```
ถ้าอยากได้แผนทั้งสัปดาห์ ใช้ `content-calendar` (วางรูปแบบของแต่ละวันก่อน ขอให้นักเรียนยืนยันก่อนเขียนเต็ม)

## ข้อมูลที่ทีมอ่าน
| โฟลเดอร์ | คืออะไร |
|---|---|
| `characters/<ชื่อ>/` | **character DNA** 7 ไฟล์: ตัวตน/หน้าตาที่ล็อก (`character_dna.md`), บุคลิก, น้ำเสียงพูด, อารมณ์ขัน, ภาพลักษณ์, ข้อห้าม, เป้าหมายธุรกิจ |
| `content_dna/` | โครงของเนื้อหาแต่ละประเภท (ugc, educational, comedy, product_review ฯลฯ) |
| `format_bibles/` | วิธีถ่าย/ท่าทางแต่ละสไตล์ (กล้อง สายตา การเคลื่อนไหว แสง สิ่งที่ห้ามทำ) |
| `model_specs/` | ข้อกำหนดของโมเดลปลายทาง (minimax-h3 = วิดีโอ, krea = ภาพ) รวมความยาว/โครง prompt |
| `platform_specs/` | ข้อกำหนดแต่ละแพลตฟอร์ม (TikTok, Reels, Shorts ฯลฯ) |
| `schemas/` | รูปแบบข้อมูลที่ส่งต่อระหว่างชั้น |

## สร้างตัวละครของตัวเอง
1. คัดลอก `characters/TEMPLATE/` เป็น `characters/<ชื่อตัวละครของคุณ>/`
2. ให้ agent ถามคุณทีละข้อแล้วเติมทั้ง 7 ไฟล์ (หน้าตา ผม ชุดประจำ น้ำเสียง อารมณ์ขัน ข้อห้าม เป้าหมาย)
3. ตั้ง `status: active` เมื่อพร้อมใช้ และ **อย่าลอกตัวอย่างของคนอื่นทั้งดุ้น** (anong/momo เป็นตัวอย่างบุคลิกเท่านั้น)
4. ดูรูปอ้างอิงตัวละคร: ครอปให้หน้าชัดตัวเดียว ไม่มีมือ/ลายน้ำ/ตัวหนังสือติดมา

## ข้อควรรู้
- pipeline เขียนมาสำหรับเนื้อหาที่ตัวละครเป็น "ผู้ใช้/พิธีกร" ในคลิปสั้น; ถ้างานของคุณเป็นแนวอื่น (เช่น คลิปเต้นล้วน) ใช้แม่แบบใน `prompts/` ตรงๆ ได้
- บางตัวละครตัวอย่างและ content_dna (เช่น momo, flirty, fan_interaction) ออกแบบมาเพื่อเนื้อหาแนวเกี้ยวพาราสี/ผู้ติดตามจ่ายเงิน (รวมระดับ NSFW) เก็บไว้เป็นตัวอย่าง: **ใช้ตามกติกาแพลตฟอร์มและกฎหมาย สำหรับผู้ใหญ่เท่านั้น** และตัวละครที่นักเรียนสร้างเองต้องมีข้อห้ามชัดใน `constraints.md`
- ผลลัพธ์ยังต้องให้คุณตรวจเสมอ: เวลาพูดเป็นการประมาณ รูปแบบ experimental ยังไม่ผ่านการเรนเดอร์
- เอา prompt ไปรันใน workflow: ดู `docs/USE_WORKFLOW.md` (คุณกดรันเอง) · ทำ storyboard ก่อนเขียน prompt ได้ด้วย `storyboard-builder`
