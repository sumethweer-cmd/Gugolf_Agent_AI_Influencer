# RULES — บทเรียนการเขียน prompt (พร้อมระดับความมั่นใจ)

ป้าย: **[ยืนยัน]** = เห็นผลชัดจากการทดสอบจริง · **[ทดสอบครั้งเดียว]** = เห็นผลครั้งเดียว ยังไม่ใช่กฎ · **[สมมติฐาน]** = เดา/มาจากเอกสารหรือคำแนะนำภายนอก ยังไม่ทดสอบ

## คลิปเต้นที่ก๊อปท่าจาก DWPose (`<Video 1>`)
- **[ยืนยัน]** ห้ามใส่ timestamp ในส่วนสีหน้า/การกระทำ: ไทม์ไลน์แบบ `00:01.000-00:02.500: ...` ทำให้ท่าเต้นเพี้ยนจากคลิปอ้างอิง ใช้ `[Shot 1]` เดียวและเขียนสีหน้าเป็นร้อยแก้ว
- **[ยืนยัน]** `<Video 1>` ใช้เป็น "การเคลื่อนไหวของร่างกาย" เท่านั้น ห้ามเขียน "สีหน้าเหมือน Video 1" ให้เขียนสีหน้าเอง (ตา สายตา คิ้ว ปาก รอยยิ้ม) เป็นการกระทำที่มองเห็นได้
- **[ยืนยัน]** ระบุปากให้ชัด: ปากเปิดตามเพลง ("silently mouthing along") หรือปากนิ่ง ("silent dancer") ถ้าไม่ระบุ โมเดลอาจร้องเพลงที่แต่งเอง
- **[ยืนยัน]** ห้ามเขียนองศาหัว/ท่าลำตัวทับ DWPose ปล่อยให้ pose คุม
- **[ยืนยัน]** คลิปอ้างอิงยาวกว่า segment ไม่ต้องตัดเอง node แบ่งให้; ทุก segment อ้าง `<Video 1>`
- **[ทดสอบครั้งเดียว]** ตัวละครสัตว์/การ์ตูนเต้นได้ถ้าเขียนส่วนที่ขยับ (หู หาง ขน) แทนผมยาว; ตัวละครใส่แว่นกันแดด → ตัดประโยคสายตาออก
- **[สมมติฐาน]** เปลี่ยนชุดกลางคลิปด้วย timestamp อาจกวนท่า; วิธีปลอดภัยคือเรนเดอร์สองรอบแล้วเปลี่ยนที่ตัดต่อ

## รูปอ้างอิงและข้อความ
- **[ยืนยัน]** **ข้อความชนะรูปเมื่อขัดกัน** (ข้อความบอกเสื้อเขียว รูปเป็นชุดดำ → ได้เสื้อเขียว) ถ้าไม่เขียนชุดในข้อความ รูปจะกำหนดชุด/ฉาก
- **[ยืนยัน]** อย่าส่ง character sheet หลายช่อง/มีหุ่นไม่มีหัวเป็น Picture 1 ให้ครอปเฉพาะช่องที่ต้องการ
- **[ยืนยัน]** รูปที่มีมือ ลายน้ำ หรือตัวหนังสือติดมา อาจหลุดเข้าคลิป ครอปให้สะอาด
- **[ทดสอบครั้งเดียว]** framing มักกว้างกว่าที่เขียน ถ้าอยากได้ใกล้ใช้รูปที่หน้า–อกเต็มเฟรมและเขียนกำกับ

## เสียงและบท
- **[ยืนยัน]** คัดลอก prompt จากไฟล์ดิบ ไม่ใช่หน้าเว็บที่เรนเดอร์ markdown (แท็ก `<Picture 1>` หาย)
- **[สมมติฐาน]** เวลาพูดไทย ~3.2 คำ ICU/วินาที (แบ่งด้วย `Intl.Segmenter('th')`) + ~0.4 วินาทีระหว่างประโยค ใช้ประมาณเท่านั้น ไม่เคยวัดจากเสียงจริง; เว้นเผื่อท้ายคลิปอย่างน้อย 1 วินาที
- **[สมมติฐาน]** ~1 ประโยคสั้นต่อ 2.5 วินาที; steps 8 สำหรับเสียงไทย (4 steps ทำพยางค์หาย)
- context segment: ไทม์สแตมป์ตกเร็วไปราว 0.92 วินาที เขียน T + 0.92 เพื่อให้ตกที่ T; เปิด segment ด้วยการต่อเนื่อง ไม่ใส่คำบรรยายฉาก; ต่อที่รอยต่อประโยค/กลางการเคลื่อนไหว ไม่ต่อที่ธรณีประตู

## การเขียนทั่วไป
- เขียนเชิงบวก (หลีกเลี่ยง no/not/without) เป็นค่าเริ่มต้น แต่ถ้าต้องกันของ/คนที่ไม่ควรอยู่ในฉาก ให้ระบุสถานะที่ต้องการชัดเจน **[ทดสอบครั้งเดียว]**
- ไม่ใช้คำที่ทำให้ผิวเป็นประกายจนดูปลอม (dewy, glow, flawless, shimmer, wet skin) ถ้าต้องการผิวสมจริง ใช้รายละเอียด matte, pores, peach fuzz **[สมมติฐาน]**
- ของในมือ: ระบุมือไหนถือ วางลงเมื่อไหร่; หนึ่ง action ต่อ shot; ท่าละเอียดหลายนิ้วในเวลาสั้นเสี่ยงมือเพี้ยน **[ทดสอบครั้งเดียว]**
- คลิปสินค้า/โฆษณา: ไม่แต่งราคา สต็อก หรือสรรพคุณ คำบรรยายสินค้าต้องตรงกับของจริง และติดป้ายโฆษณา/สปอนเซอร์ตามกติกาแพลตฟอร์มในขั้นตัดต่อ
