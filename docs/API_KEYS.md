# API_KEYS — ตอนไหนต้องใช้ key และเอาไปใส่ตรงไหน

> กฎเหล็ก: **ห้ามวาง API key ในแชทกับ AI, ห้ามส่งต่อ, ห้าม commit ลง git** กรอกในไฟล์ `.env` ด้วยตัวเองเท่านั้น ใครมี key ใช้เครดิตของคุณได้

## สรุปสั้น: คุณต้องมี key ไหม?
| คุณใช้อะไร | ต้องมี key ไหม |
|---|---|
| **Codex** (มีเครื่องมือสร้างรูปในตัว) | **ไม่ต้อง** agent สร้างรูป storyboard เองได้เลย |
| **Claude Code** (สร้างรูปเองไม่ได้) | **ถ้าอยากได้รูป storyboard** ต้องมี key ของ **OpenAI หรือ Gemini** อย่างใดอย่างหนึ่ง (หรือข้ามรูป ใช้ storyboard แบบข้อความได้) |
| แค่เขียน prompt / คิดไอเดีย / ตัวละคร | **ไม่ต้อง** key ใดๆ |
| รัน workflow บนเว็บ RunningHub | ไม่ต้องใช้ API key (ล็อกอินบัญชีบนเว็บแล้วรันเอง) ดู `docs/USE_WORKFLOW.md` |

## ขอ key สร้างรูป (เฉพาะกรณี Claude Code ที่อยากได้รูป storyboard)
เลือกอย่างใดอย่างหนึ่ง:

**OpenAI:** สร้าง key ที่ https://platform.openai.com/api-keys — การสร้างรูปมีค่าใช้จ่ายตามการใช้งาน และบางโมเดลรูปภาพอาจต้องผูกบัตร/ยืนยันบัญชีก่อน (ตรวจเงื่อนไขและราคาล่าสุดในเว็บของ OpenAI เอง)

**Gemini:** สร้าง key ที่ https://aistudio.google.com/apikey — เงื่อนไขโควต้า/ฟรี/ราคาเปลี่ยนได้ ตรวจในเว็บเอง

ข้อควรระวัง:
- ชื่อโมเดลในสคริปต์ (`gpt-image-1`, `gemini-2.5-flash-image`) อาจล้าสมัย ถ้า error ว่าไม่พบโมเดล ให้บอก agent แล้วตรวจชื่อโมเดลปัจจุบันด้วยกัน
- ตั้งเพดานการใช้จ่ายในเว็บผู้ให้บริการถ้ามี และสร้างรูปทีละฉาก ดูผลก่อนฉากถัดไป

## เอา key ไปใส่ตรงไหน
1. ในโฟลเดอร์โปรเจกต์ ก๊อปไฟล์ `.env.example` เป็นชื่อ `.env`
2. เปิด `.env` ด้วยโปรแกรมแก้ไขข้อความ ใส่ key ต่อท้ายเครื่องหมาย `=` ของบรรทัดที่ต้องการ (ไม่มีเว้นวรรค ไม่มีเครื่องหมายคำพูด ไม่ต้องใส่คอมเมนต์ในบรรทัดเดียวกัน):
```text
OPENAI_API_KEY=ค่า key ของคุณ
GEMINI_API_KEY=
```
3. บันทึกไฟล์ จากนั้นให้ agent รัน `.claude/skills/storyboard-builder/scripts/doctor.sh` ซึ่งตรวจว่ามี key แค่ไหน **โดยไม่แสดงค่า key**
4. `.env` ถูกกันไว้ใน `.gitignore` แล้ว ห้ามเอาไฟล์นี้ไปอัปโหลดหรือส่งให้ใคร

## ถ้า key หลุด
เข้าเว็บของผู้ให้บริการ ลบ/ยกเลิก key นั้นแล้วสร้างอันใหม่ จากนั้นแก้ `.env`
