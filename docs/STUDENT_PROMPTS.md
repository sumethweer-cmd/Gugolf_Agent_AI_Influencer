# STUDENT_PROMPTS — ข้อความสำเร็จรูปให้นักเรียนวางกับ agent (Claude Code / Codex)

เปิด agent ในโฟลเดอร์ที่จะทำงาน แล้ววางข้อความตามงานที่ต้องการ (เปลี่ยน `<...>` เป็นของคุณ) ทุกข้อความบอก agent ให้ทำตาม `AGENTS.md` ในรีโป ซึ่งมีกฎความปลอดภัยและเรื่องเงินอยู่แล้ว

> ข้อควรจำ: **อย่าวาง API key ในแชท** — กรอกในไฟล์ `.env` เอง

---

## A) ตั้งค่าครั้งแรก
```text
ช่วยตั้งค่าชุดเครื่องมือสร้างคลิป AI จากรีโปนี้ให้ฉัน: https://github.com/sumethweer-cmd/Gugolf_Agent_AI_Influencer

ทำตาม AGENTS.md ในรีโป และทำตามนี้ตามลำดับ:
1. git clone รีโป แล้วอ่าน AGENTS.md และ docs/SETUP.md
2. ตรวจว่าเครื่องฉันมี Node.js 18 ขึ้นไป และ git (ffmpeg ถ้ามี) แล้วรายงานผล ถ้าขาดอะไร บอกวิธีติดตั้ง ห้ามติดตั้งเองโดยไม่ถาม
3. สร้างไฟล์ .env จาก .env.example แต่ห้ามกรอก API key ให้ ให้บอกฉันกรอกเอง แล้วตรวจแค่ว่าตัวแปรที่จำเป็นไม่ว่าง โดยไม่แสดงค่า
4. ทดสอบสคริปต์แบบไม่เสียเงิน: รัน gen_ugc_prompts.mjs กับไฟล์ตัวอย่างด้วย --check
5. สรุปให้ฉันว่ายังต้องเตรียมอะไรเองบ้าง (workflow, โมเดล, บัญชี RunPod/RunningHub) แบบเป็นข้อๆ
ห้ามส่งงานเรนเดอร์ ห้ามเปิดหรือหยุด pod ในขั้นตอนนี้
```

## B) ให้ agent ช่วยเขียน prompt คลิป
```text
ช่วยเขียน prompt คลิปวิดีโอให้ฉัน โดยใช้รีโป Gugolf_Agent_AI_Influencer ที่โคลนไว้แล้ว ทำตาม AGENTS.md

1. อ่าน docs/RULES.md และเลือกแม่แบบที่ตรงกับงานจากโฟลเดอร์ prompts/ (บอกฉันว่าแม่แบบนั้นเป็น verified หรือ experimental)
2. ถามฉันทีละข้อสั้นๆ: ตัวละครและรูปอ้างอิง, ฉากหลัง/มุมกล้อง, วิดีโอท่าอ้างอิง (ถ้ามี), บทพูดภาษาไทย (ถ้ามี), ความยาวกี่วินาที
3. เขียน prompt ตามแม่แบบ อย่าเดาสูตรเอง คำนวณเวลาพูดให้พอดีความยาวและเผื่อท้ายคลิป 1 วินาที
4. ตรวจก่อนส่งให้ฉัน: ไม่มี timestamp ในคลิปเต้นที่ก๊อปท่า, ระบุปากชัด, ตัวเลขเป็นคำไทย, ประโยคจบด้วย . ? !
5. บันทึกผลเป็นไฟล์ .txt ในโฟลเดอร์งานของฉัน และสรุปเป็นไทยว่าควรตั้งค่าอะไร (เฟรม, steps, MP)
ห้ามส่งงานเรนเดอร์ในขั้นตอนนี้
```

## C) สั่งเรนเดอร์ (เสียเงิน/เวลา GPU)
```text
ช่วยสั่งเรนเดอร์คลิปให้ฉัน ทำตาม AGENTS.md และ .claude/skills/ugc-render-ops/SKILL.md

Provider: <RunPod หรือ RunningHub>   (ถ้า RunPod ฉันจะให้ URL ของ pod: <https://...-8188.proxy.runpod.net>)
ไฟล์ prompt: <ชื่อไฟล์/โฟลเดอร์>   รูปอ้างอิง: <path รูป>   ความยาว: <กี่ segment / กี่วินาที>

1. เตรียม config ตามตัวอย่างใน .claude/skills/ugc-render-ops/templates/ แล้วทำ dry-run
2. สรุปให้ฉัน: provider, จำนวน segment, วินาทีรวม, ประมาณเวลาและต้นทุน, รูปที่ใช้เป็น Picture ไหน
3. รอให้ฉันพิมพ์ยืนยันก่อน แล้วค่อยส่งจริงด้วย --go --nowait
4. ห้ามหยุด/ลบ pod เองถ้าฉันไม่สั่ง และห้ามเขียนอะไรลงบริการภายนอกที่ฉันไม่ได้อนุญาต
```

## D) เช็กสถานะ / เก็บผล / หยุด pod
```text
ช่วยเช็กงานเรนเดอร์ที่ค้างอยู่ของฉัน ทำตาม AGENTS.md

1. รัน --status ของสคริปต์เรนเดอร์ที่ใช้ (runpod_render.mjs หรือ runninghub_run.mjs) แล้วสรุปเป็นตารางสั้นๆ
2. ถ้ามีงานที่สำเร็จ ให้ --collect เพื่อโหลดคลิปลงเครื่อง แล้วบอกชื่อไฟล์
3. ถ้ามีงานล้ม ให้ดูข้อความ error และบอกสาเหตุที่เป็นไปได้ อย่าเดาว่าแก้แล้ว
4. ถ้าเป็น RunPod ให้เตือนฉันว่า pod ยังเปิดอยู่ไหม แต่รอให้ฉันสั่งก่อนจึงหยุด pod (--confirm)
```

## E) เรนเดอร์ล้ม / เครื่องล่ม
```text
งานเรนเดอร์ของฉันล้ม ช่วยหาสาเหตุ โดยทำตาม AGENTS.md และ docs/SETUP.md

ข้อความ error ที่เห็น: <วางข้อความ error หรือท้ายไฟล์ล็อก>

1. อ่านข้อความแล้วบอกว่าเกี่ยวกับอะไร (SageAttention, OOM, ไฟล์หาย, node หาย ฯลฯ) และบอกระดับความมั่นใจ
2. ให้คำสั่งตรวจเพิ่มเติมที่อ่านอย่างเดียวก่อน ห้ามแก้อะไรบน pod จนกว่าฉันจะสั่ง
3. เสนอทางแก้ 2-3 ทาง พร้อมข้อดีข้อเสีย แล้วรอให้ฉันเลือก
```
