# STUDENT_PROMPTS — ข้อความสำเร็จรูปให้นักเรียนวางกับ agent (Claude Code / Codex)

เปิด agent ในโฟลเดอร์ที่จะทำงาน แล้ววางข้อความตามงานที่ต้องการ (เปลี่ยน `<...>` เป็นของคุณ) ทุกข้อความบอก agent ให้ทำตาม `AGENTS.md` ในรีโป ซึ่งมีกฎความปลอดภัยอยู่แล้ว

> ข้อควรจำ: **อย่าวาง API key ในแชท** — ถ้าต้องใช้ key (เฉพาะสร้างรูป storyboard ด้วย API) กรอกในไฟล์ `.env` เอง
> agent ในรีโปนี้ช่วย **สร้าง prompt และสอน** เท่านั้น การรันเรนเดอร์คุณกดเองบนเว็บ RunningHub

---

## A) เริ่มต้นแบบมีพี่เลี้ยง (ใช้อันนี้ก่อน)
```text
ช่วยฉันเริ่มต้นใช้ชุดเครื่องมือสร้าง prompt คลิป AI จากรีโปนี้: https://github.com/sumethweer-cmd/Gugolf_Agent_AI_Influencer

ฉันเป็นมือใหม่ ให้คุณทำตัวเป็นพี่เลี้ยง ทำตามนี้:
1. ติดตั้งก่อน: git clone รีโปลงโฟลเดอร์ที่ฉันอยู่ แล้วอ่าน AGENTS.md และทำตามทั้งหมด รวมถึงหัวข้อ "โหมดพี่เลี้ยง"
2. ตรวจเครื่อง (Node.js 18 ขึ้นไป, git) ถ้าขาดอะไร บอกวิธีติดตั้งแล้วรอให้ฉันยืนยัน ห้ามติดตั้งเองโดยไม่ถาม
3. ถามฉันก่อนว่าฉันใช้ agent ตัวไหน (Claude Code หรือ Codex) แล้วบอกตามจริงว่าเรื่องสร้างรูป storyboard ต้องใช้ API key ไหมสำหรับตัวที่ฉันใช้ (อย่าให้ฉันวาง key ในแชท ให้ฉันกรอกใน .env เอง)
4. ช่วยฉันคิดไอเดียคลิป (ถามว่าอยากทำอะไร แล้วเสนอ 5 ไอเดีย), เลือกหรือสร้างตัวละคร (character DNA) และสร้าง prompt ผ่านทีมสร้าง prompt ในรีโป
5. สอนฉันไปพร้อมๆ กัน ทีละเรื่อง อธิบายสั้นๆ ว่าทำไม ถามทีละข้อ อย่าส่งข้อความยาวทีเดียว
6. พอได้ prompt แล้ว สอนฉันเอาไปรันใน workflow บนเว็บ RunningHub ด้วยตัวเอง (ตาม docs/USE_WORKFLOW.md) เริ่มจากคลิปทดสอบสั้นๆ
7. ถ้าไม่แน่ใจอะไร (เช่นเมนูบนเว็บ) บอกว่าไม่แน่ใจ อย่าเดา
8. บันทึกความคืบหน้าในไฟล์ STUDENT_PROGRESS.md (ห้ามใส่ key)
```

## B) ให้ agent ช่วยเขียน prompt คลิป
```text
ช่วยเขียน prompt คลิปวิดีโอให้ฉัน โดยใช้รีโป Gugolf_Agent_AI_Influencer ที่โคลนไว้แล้ว ทำตาม AGENTS.md

1. อ่าน docs/RULES.md และเลือกแม่แบบหรือ pipeline ที่ตรงกับงาน (บอกฉันว่าแม่แบบนั้นเป็น verified หรือ experimental)
2. ถามฉันทีละข้อสั้นๆ: ตัวละครและรูปอ้างอิง, ฉากหลัง/มุมกล้อง, วิดีโอท่าอ้างอิง (ถ้ามี), บทพูดภาษาไทย (ถ้ามี), ความยาวกี่วินาที
3. เขียน prompt ตามแม่แบบ อย่าเดาสูตรเอง คำนวณเวลาพูดให้พอดีความยาวและเผื่อท้ายคลิป 1 วินาที
4. ตรวจก่อนส่งให้ฉัน: ไม่มี timestamp ในคลิปเต้นที่ก๊อปท่า, ระบุปากชัด, ตัวเลขเป็นคำไทย, ประโยคจบด้วย . ? !
5. บันทึกผลเป็นไฟล์ .txt ในโฟลเดอร์งานของฉัน และสรุปเป็นไทยว่าควรตั้งค่าอะไร (เฟรม, steps, MP)
```

## C) ทำ storyboard
```text
ช่วยทำ storyboard ให้ไอเดียนี้: <เล่าไอเดียสั้นๆ หรือชื่อไฟล์ prompt/ไอเดียที่ทำไว้> ตัวละคร: <ชื่อตัวละคร>
ทำตาม AGENTS.md และ .claude/skills/storyboard-builder/SKILL.md

1. บอกฉันก่อนว่า agent ที่ฉันใช้สร้างรูปเองได้ไหม ถ้าไม่ได้ ให้บอกตรงๆ ว่าต้องใช้ OpenAI หรือ Gemini API key และถามว่าฉันอยากทำรูปไหม หรือเอาแค่ storyboard แบบข้อความ
2. เขียน storyboard แบบข้อความทีละฉากให้ฉันอนุมัติก่อน (ตัวละคร ฉาก บท แสง กล้อง การกระทำเป็นลำดับ)
3. ถ้าจะสร้างรูป: บอกประมาณค่าใช้จ่าย/จำนวนรูป ถามยืนยัน แล้วสร้างทีละฉาก ดูผลกับฉันก่อนฉากถัดไป
```

## D) สอนเอา prompt ไปรันใน workflow
```text
ฉันได้ prompt แล้ว ช่วยพาฉันเอาไปรันใน workflow บน RunningHub ทีละขั้น ตาม docs/USE_WORKFLOW.md
(workflow: https://www.runninghub.ai/workflow/2111495230942896130)

ฉันจะรันเอง คุณช่วยแค่บอกทีละขั้น ถามฉันว่าเห็นอะไรบนหน้าจอ และถ้าไม่แน่ใจเรื่องเมนูบนเว็บ ให้บอกว่าไม่แน่ใจ อย่าเดา
เริ่มจากคลิปทดสอบสั้นๆ 3-5 วินาที และเตือนฉันให้ดูราคา/เครดิตในบัญชีตัวเองก่อนกดรันคลิปยาว
```

## E) คลิปออกมาไม่ดี ช่วยปรับ prompt
```text
ผลที่ได้ไม่ตรงที่ต้องการ ช่วยปรับ prompt โดยทำตาม AGENTS.md และ docs/RULES.md

สิ่งที่เห็น: <เล่าว่าเพี้ยนตรงไหน เช่น ท่าเต้นไม่ตาม / ร้องเพลงเอง / ชุดไม่ตรงรูป / มือเพี้ยน>
prompt ที่ใช้: <วางหรือบอกชื่อไฟล์>

1. บอกว่าสาเหตุที่เป็นไปได้มีอะไรบ้าง พร้อมระดับความมั่นใจ (อย่าฟันธง)
2. เสนอการแก้ 2-3 แบบ แล้วรอให้ฉันเลือก
3. เขียน prompt ฉบับแก้ใหม่เป็นไฟล์ใหม่ (อย่าเขียนทับของเดิม) แล้วบอกว่าเปลี่ยนอะไร
```
