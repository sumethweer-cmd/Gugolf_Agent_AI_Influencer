# Gugolf Agent — AI Influencer Video Toolkit

ชุดเครื่องมือและ prompt สำเร็จรูปสำหรับทำคลิป AI ด้วย **MiniMax H3** (ผ่าน ComfyUI + Easy-Media "Motion Context V2") แล้วสั่งเรนเดอร์เป็น batch ผ่าน **RunPod** หรือ **RunningHub** โดยให้ AI agent (Claude Code หรือ Codex) ช่วยเขียน prompt, ตั้งค่า, สั่งงาน และเก็บผลให้

> สถานะ: ชุดเริ่มต้นจากงานทดลองจริง — แม่แบบที่ติดป้าย **verified** ผ่านการทดสอบแล้ว ที่ติดป้าย **experimental** ยังไม่ผ่านการเรนเดอร์ ใช้เป็นจุดเริ่มต้นแล้วรายงานผลกลับมา

## ต้องมีอะไรก่อน
- **Claude Code หรือ Codex** (agent ที่รันคำสั่งในเครื่องคุณได้) — แนะนำอย่างยิ่ง เพราะงานนี้ต้องรันสคริปต์ อ่านไฟล์ และตรวจผล
- Node.js 18+, git, (ไม่บังคับ) ffmpeg
- บัญชี RunPod และ/หรือ RunningHub + API key (กรอกใน `.env` เอง **ห้ามวางให้ AI**)
- workflow "MiniMax H3 Motion Context V2" + โมเดล/custom node ที่ติดตั้งเอง (**ไม่อยู่ในรีโปนี้** อ่านเงื่อนไข license ของแต่ละตัว) — ดู [`docs/SETUP.md`](docs/SETUP.md)

## เริ่มใช้งาน (วางให้ agent)
เปิด Claude Code/Codex ในโฟลเดอร์ว่างที่คุณจะทำงาน แล้ววางข้อความนี้:

```text
ช่วยตั้งค่าและใช้ชุดเครื่องมือสร้างคลิป AI จากรีโปนี้ให้ฉัน: https://github.com/sumethweer-cmd/Gugolf_Agent_AI_Influencer

ทำตามนี้:
1. โคลนรีโป (git clone) แล้วอ่าน AGENTS.md ก่อน จากนั้นอ่านเฉพาะไฟล์ที่เกี่ยวกับงานที่ฉันบอก และทำตามขั้นตอนและกฎใน AGENTS.md
2. ก่อนเริ่ม ถามฉันสั้นๆ: ใช้ RunPod หรือ RunningHub, มี API key แล้วหรือยัง, ติดตั้ง workflow/โมเดลครบหรือยัง, อยากทำคลิปแบบไหนและยาวกี่วินาที
3. อย่าขอให้ฉันวาง API key ในแชท ให้บอกฉันกรอกไฟล์ .env เอง แล้วตรวจแค่ว่าตัวแปรไม่ว่างโดยไม่แสดงค่า
4. ทำ dry-run ก่อนเสมอ และถามยืนยันก่อนส่งงานที่เสียเงินหรือเวลา GPU; ห้ามหยุด/ลบ pod เองถ้าฉันไม่สั่ง
5. เขียน prompt จากแม่แบบในโฟลเดอร์ prompts/ ห้ามเดาสูตรเอง ถ้าแม่แบบติดป้าย experimental ให้บอกฉันก่อน
```

## หลักการ (สรุป)
- **เงินและความลับ:** ส่งจริงต้อง `--go` และได้ยืนยัน, key อยู่ใน `.env` เท่านั้น, ไม่ commit ผลลัพธ์/ไฟล์สื่อ
- **ไม่มี timestamp ในคลิปเต้นที่ก๊อปท่า**, ระบุปากให้ชัด, สีหน้าเขียนเป็นร้อยแก้ว (ดู `docs/RULES.md`)
- รายงานผลทดสอบของคุณกลับมาจะช่วยให้ปรับแม่แบบที่ยังเป็น experimental
